About

What this is

BraillePay is a prototype for verifying the contents of a QR code independently, using sound and vibration instead of sight — built around a real 6-dot Braille cell.

What it deliberately withholds

During a scan, BraillePay only ever announces whether a character is a letter or a digit — never the letter or digit itself. The full Braille dot pattern is still shown and vibrated out in full, so a Braille-literate user can independently read the actual value themselves.

What this is not

There is no camera upload, no real UPI or bank linkage, and no real payment anywhere in this app. The verification screen you see during a scan is entirely simulated for demonstration; QR content is decoded on-device and never transmitted.
